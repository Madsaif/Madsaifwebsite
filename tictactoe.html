About This Game

Tic Tac Toe is a simple yet engaging strategy game created with HTML, CSS, and JavaScript. Players compete against each other by placing X and O marks on a 3×3 grid to achieve three matches in a row.

With a clean interface and interactive gameplay, Tic Tac Toe offers a smooth gaming experience suitable for all ages. The game is lightweight, responsive, and perfect for quick entertainment.

Key Features

  • Two-player interactive gameplay
  • Win, draw, and reset functionality
  • Responsive and modern UI design
  • Fast and lightweight performance
